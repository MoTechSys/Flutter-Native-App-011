## 1. السياق ومعايير التقييم

المشروع أحد ثلاثة مشاريع طلابية (CarCare 011 · EduAcademy 022 · Kitabi 033) تُقيَّم على ملف "متطلبات مشروع فلاتر":

| المعيار | الدرجة |
|---|---|
| التصميم والغنى (≥5 شاشات غير المصادقة، Widgets متنوعة، Assets، Row/Column/Stack، ListView/GridView) | 5 |
| المصادقة (Form/Validation + نسيت كلمة المرور فعّالة) | 3 |
| الاستجابة الديناميكية (StatefulWidget، SnackBar، Dialog) | 4 |
| SQLite CRUD | 5 |
| التنقل مع تمرير بيانات + تعدد الملفات + APK | 3 |

**سجل السيارة الذكي: إدارة الزيت، الإطارات، البطارية، الصيانة الدورية، استهلاك الوقود وتاريخ الإصلاحات.**

## 2. متطلبات صاحب المشروع الثابتة (تنطبق على المشاريع الثلاثة)

| الطلب | التنفيذ |
|---|---|
| ترخيص عن بُعد يمكن **إيقافه** من ملف في GitHub | `license.json`: `active:true` يفتح فوراً · `false` يطلب كوداً ويُحفظ بعد نجاحه · حذف الملف (404) قفل نهائي · بلا إنترنت = آخر حالة |
| "نسيت كلمة المرور" **تعمل فعلاً** لا شكلياً | محرك OTP بثلاث خطوات: رمز يُعرض للمستخدم، صلاحية زمنية، محاولات محدودة، ثم UPDATE فعلي في SQLite |
| أيقونة تطبيق بلا مربعات سوداء | أيقونة متكيّفة (`mipmap-anydpi-v26` + طبقتا خلفية/مقدمة) |
| نفس مفتاح التوقيع لكل المشاريع | `release-key.jks` (alias `release`، SHA-256 `52:BE:39:E7:F4:16…`) |
| توثيق داخل المستودع + نسخة مرجعية + روابط تحميل مباشرة | `docs/` + `releases/` + `BUILD_GUIDE.md` |
| لا يخرج التطبيق فجأة، ولا Overflow على الشاشات الصغيرة | اختبارات widget على 360×780 + فحص بصري آلي |

## 4. المشاكل التي ظهرت وحلولها

| # | المشكلة | السبب | الحل |
|---|---|---|---|
| 1 | Overflow في عناصر قوائم الصيانة/الوقود/الإصلاحات وفي شاشة الدخول | أبعاد ثابتة على شاشات 360px | إعادة التخطيط بـ Expanded/Wrap + اختبارات widget على 360×780 |
| 2 | الترخيص يتأخر بعد تعديل license.json | كاش CDN لـ raw.githubusercontent | GitHub Contents API أولاً |
| 3 | صورة Asset لا تظهر | مسار خاطئ في pubspec | تصحيح المسار |
| 4 | اختبارات الواجهة تتجمّد عند استعلام SQLite | sqflite_ffi على isolate حقيقي داخل FakeAsync | `tester.runAsync` حول كل تفاعل يمسّ القاعدة |
| 5 | أيقونة داخل مربع أسود | بلا طبقات adaptive | `mipmap-anydpi-v26` + طبقات |
| + | صلاحية token GitHub تنتهي فيفشل الدفع | جلسة مؤقتة | إعادة إعداد بيئة GitHub ثم الدفع |
| + | العمليات الطويلة (اختبار/بناء) تُلغى بمهلة الأداة | مهلة دقيقتين | تشغيل منفصل في الخلفية وقراءة السجل |
